# 产品分析一体化平台 — 开发需求文档

> 版本: V2.0 | 日期: 2026-07-22 | 基于 V1.1 前后端完整开发

---

## 一、项目概述

### 1.1 定位
销售数据分析 SaaS 平台，整合「产品宽度分析」「潜力产品分析」「销售数据分析」三大业务模块，面向销售部门管理者、团队负责人、数据分析师。

### 1.2 技术栈
| 层 | 技术 |
|---|------|
| 前端 | 原生 JS SPA + Chart.js 4.4 + XLSX.js 0.18 |
| 后端 | Python FastAPI + SQLite + JWT |
| 部署 | 单文件启动 `python backend/main.py`，端口 8800 |

---

## 二、整体布局架构

### 2.1 顶栏
- 左侧：平台名称「产品分析一体化平台」
- 右侧：用户头像 + 姓名 + 角色 + 下拉菜单（权限设置/修改密码/退出）

### 2.2 左侧导航
- **一级导航**：数据总览 / 产品宽度分析 / 潜力产品分析 / 账号管理
- **二级菜单**：根据选中的一级导航动态切换
- 支持展开/收缩（◀ 按钮），收缩后仅显示图标
- 选中项蓝色高亮（`#1a56db`）

### 2.3 右侧内容区
- 自适应宽度，侧边栏变化时平滑过渡

### 2.4 筛选栏（filter-bar）
- 日期选择器：点击弹出下拉面板，包含开始日期/结束日期 + 快捷按钮（7天/14天/30天）
- 部门 → 组 → 个人 三级级联下拉
- 对比期选择

## 四、产品宽度分析

### 4.1 二级菜单
总览分析 → 产品维度 → 团队维度 → 客户维度 → 用户维度 → 分组对比 → 数据导入与管理 → AI建议与分析

### 4.2 各 Tab 功能

**总览分析**
- KPI 行（4卡片）
- 人均产品宽度分布 + 产品宽度柱图
- 产品覆盖率柱图（客户/用户切换）
- 产品覆盖热力图（27品类）
- 产品宽度历史趋势折线

**团队维度**
- 数据明细表：部门/组/个人三维度，含27品类列 + 宽度进度条 + 规上/非规上徽章
- 排序/搜索/分页/导出
- 点击规上/非规上徽章 → 弹窗明细（账号汇总 + 客户明细）
- 差距分析：全部时显示「部门 vs 业务中心均值」

**客户维度**
- 🔍 低宽度客户分析：阈值输入 + 统计卡片 + TOP20列表 + 部门/组柱状图（可点击钻取）
- 客户产品宽度覆盖：优质top10 / 待提升后10
- 📋 客户产品覆盖明细：跟随筛选 + 分页 + 规上/搜索/排序
- 🎯 客户分层分析（已移至潜力产品页）

**用户维度**
- 🔍 低宽度用户分析：同客户维度逻辑（用户维度数据）
- 用户产品宽度覆盖：优质top10 / 待提升后10
- 📋 用户产品覆盖明细：27品类 + 分页 + 列宽拖拽

**分组对比**
- 6种模式：部门vs业务中心 / 部门vs部门 / 组vs部门 / 组vs组 / 个人vs组 / 个人vs个人
- 下拉列表根据页级筛选动态限定范围
- 综合指标对比表 + 产品覆盖率雷达图（27品类） + 产品覆盖对比表
- 雷达图高度 750px，图例右上

**数据导入与管理**
- 📜 历史数据管理：上传快照 + 恢复/删除/清空 + 下载当前数据
- 📂 产品宽度总表：上传文件（自动识别用户/客户Sheet）+ 双击编辑 + 批量删除 + 列宽拖拽 + 分页
- 右上角标签切换「规上用户」/「规上客户」视图
- 导入按客户名称/用户名称自动识别新增与更新

**AI建议与分析**
- 双Tab：智能分析 + API配置
- 5个快捷提问（部门宽度/产品线短板/客户提升/团队预警/策略建议）
- 自动构建数据上下文 → MaaS API → 渲染结果
- 支持复制结果
- API配置 localStorage 持久化

## 七、通用交互规范

### 7.1 筛选联动
- 部门 → 组 → 个人 三级级联，下层自动重置
- 所有图表/表格自动跟随筛选刷新

### 7.2 弹窗
- 规上/非规上/客均宽度 点击弹出明细弹窗
- 弹窗尺寸 95vw × 92vh
- 包含账号汇总 + 客户明细表 + 导出按钮

### 7.3 日期选择器
- 统一「日期」组件，点击展开下拉面板
- 两个 date input + 快捷按钮（7/14/30天）
- 点击外部自动关闭
- 三页统一：总览/产品宽度/潜力产品

### 7.4 数据导入
- 自动识别Sheet（按表头列名）
- 支持 `.xlsx` / `.xls`
- 上传后同步到全平台 RAW 数据
- 模板文件：`assets/reference/数据导入模版-0716.xlsx`

## 八、数据模型

### 8.1 前端核心数据
| 变量 | 说明 |
|------|------|
| `App.WidthCustomer.RAW` | 产品宽度原始数据（全平台数据源） |
| `App.WidthCustomer.PRODUCTS` | 27品类列表 |
| `App.DEPTS` | 6个部门 |
| `App.GROUPS` | 18个组 |
| `App.PERSONS` | 销售人员 |
| `App.WidthTeamMatrix.RAW` | 团队×产品矩阵数据 |

### 8.2 后端数据库
| 表 | 说明 |
|----|------|
| tenants | 租户 |
| users | 用户 |
| departments | 部门 |
| groups | 组 |
| products | 产品字典 |
| sales_width | 产品宽度销售数据 |
| sales_potential | 潜力产品销售数据 |
