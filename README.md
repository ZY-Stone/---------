
## 开发规范

详见 [AGENTS.md](./AGENTS.md)。核心原则：

- **代码隔离** — 所有代码放在 `src/`，不引用 `assets/` 或 `docs/` 资源
- **文档先行** — 功能开发前先写 PRD / 迭代记录
- **笔记沉淀** — 踩坑必记录，一坑一文
- **资源分类** — 图片按用途放入 `assets/` 对应子目录
