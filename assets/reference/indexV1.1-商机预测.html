一、平台概述

商机预测管理平台用于管理销售预测、商机跟进、应收核对及备货决策。核心数据流为： 数据导入 → 数据总表 → 分析看板 → 决策支持。 各模块按月份（格式 YYYYM{MM}，如 2026M06）组织数据，支持按年/月/部门/组/销售级联筛选。

二、数据导入页 — 各模板字段说明

2.1 销售预测（sales）

字段说明逻辑
预测编号唯一标识，推荐格式：姓名+月份+序号去重键，重复则更新
预测期格式 YYYYM{MM}，如 2026M06筛选+趋势X轴
预测人 / 销售销售人员姓名按人汇总、权限过滤
所属部门 / 组组织层级级联筛选、权限隔离
非经产品预测(万)当月非经产品预测金额核心预测值
非经实际完成(万)当月实际出货金额准确率 = 实际/预测
预测达成率(%)实际完成÷预测×100评价预测质量
用户预测(万) / 用户实际(万)用户侧维度的预测与实际双维度校验
N+1/N+2月预测未来两月滚动预测趋势参考
OI/OO预测金额商机识别/商机负责维度与商机预测交叉验证

2.2 商机预测（opportunity）

字段说明逻辑
商机编号 / 商机名称唯一标识商机去重键
商机状态跟进中/报价阶段/商务谈判/合同签订漏斗分析
最终用户 / 合作伙伴客户信息应收风险关联
商机累计出库金额(万)该商机历史累计出货判断商机规模
海康产品金额(万)项目中海康能供的金额实际可及金额
中标金额 / 备货金额(万)中标和备货情况判断落地概率
商机未清金额(万)尚未出货的金额潜在应收风险
已签/未签合同金额(万)合同签订进度判断确定性
本周/本月可交付金额(万)近期可交付量现金流预测

2.3 重点商机（review）

字段说明逻辑
日期导入日期归属月份
销售负责销售按人统计分析
团队所属组按组分布
商机商机名称/描述主体标识
梳理情况跟进状态描述（自由文本）人工阅读判断，不做自动分类
⚠ 重点商机分析不自动分类梳理情况文本，所有分析仅基于销售/团队/时间等结构化维度。

2.4 应收明细（receivable）

字段说明逻辑
日期导入日期归属月份
商机名称对应商机/客户客户维度聚合键
销售负责销售归属销售
备货单金额(万)已备货金额已落实的备货
销售订单金额(万)销售订单应收金额待收金额
总计(万)汇总金额整体规模
📌 应收差额 = 销售订单金额 - 备货单金额。正值表示订单>备货（存在应收缺口），负值表示备货已覆盖订单。

三、分析看板 — 指标计算逻辑

3.1 预测分析看板（accuracy）

预测准确率 = 实际完成金额 ÷ 预测金额 × 100%
偏差率 = (预测 - 实际) ÷ 预测 × 100%
按部门/组/个人三个维度聚合，支持钻取。WAPE（加权绝对百分比误差）用于横向对比。

3.2 风险分析（risk）

覆盖度 = (已出货 + 可交付) ÷ 预测 × 100%
差距 = 预测 - (已出货 + 可交付)
风险评分 = 覆盖度分数 + 应收风险分数 + 偏差分数
红灯 覆盖度<70% 或 差距>30%
黄灯 覆盖度<85% 或 差距>15%
绿灯 其余

3.3 重点商机分析（review）

基于商机明细的结构化维度（销售/团队/时间）统计商机数量分布。
不做文本分类：梳理情况为自由文本，不进行自动状态推断。
分析维度：商机总数、团队分布、销售排行、按月趋势。

3.4 应收分析（receivable）

按客户(商机名称)维度汇总：备货单金额、销售订单金额、应收差额。
应收差额 = 销售订单 - 备货单。正值红色表示待跟进催收。

3.5 备货决策（stock）

决策模型：综合三组数据（销售预测准确率 + 应收差额 + 商机数量）
建议备货系数 = 预测准确率 - 应收风险折扣
应收风险折扣 = min(0.3, |应收差额| ÷ 预测额 × 0.5)

✅ 支持 准确率≥85% 且 应收无缺口
⚠️ 谨慎 准确率≥70% 且 缺口比<30%
❌ 不建议 准确率低或应收缺口大 → 先催收再考虑备货

四、通用功能说明

功能说明
数据导入支持 Excel(.xlsx/.xls/.csv) 和图片 OCR 导入。图片导入使用 Tesseract.js 中英双语引擎识别表格文字。
数据总表各类型数据的增删改查，支持筛选/排序/搜索/导出。导入按月份组织，逐条追加不覆盖。
级联筛选年→月→部门→组→销售，上级筛选自动限制下级可选项。
权限管理管理员/总经理/运营/部门经理/组长/销售六级角色，按可见部门过滤数据。
数据导出各数据总表支持 CSV 导出。图表为 ECharts 渲染，支持右键保存。
