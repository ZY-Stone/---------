# 数据计算过程与产品类型

> 平台的完整产品字典 + 所有 KPI 指标计算公式 + 数据流转过程。
> 来源：`models/sales_data.py` + `services/data_service.py` + `services/analytics_service.py`

---

## 🗣 大白话

平台有两种分析：产品宽度分析（看客户覆盖了多少种产品）和潜力产品分析（看哪些产品卖了多少、趋势怎样）。每种分析都有自己的一套数据表和计算公式，下面逐个展开。

## 二、两大分析模块对比

| | 产品宽度分析 | 潜力产品分析 |
|------|------------|------------|
| 数据表 | `width_records` | `potential_cust` + `potential_user` |
| 数据维度 | 用户 / 客户 | 客户 / 用户 |
| 核心指标 | 平均宽度、覆盖率、规上率 | 销售额、同比、商机数 |
| 记录结构 | 每行=一个客户/用户 + 27产品 0/1 | 每行=一个客户/用户 × 一个产品 |
| 关键字段 | `width`(产品线合计), `prods_json`(27产品0/1), `guishang` | `amount`(销售额), `qty`(数量), `opps`(商机数) |

## 三、产品宽度分析 — 计算公式

### 数据表: `width_records`

```
字段: id, record_type(user/cust), name(用户名/客户名), sales(销售),
      dept(部门), group_name(组名), guishang(是否规上),
      width(产品线合计), prods_json(27产品0/1), snapshot_period(月份)
```

### KPI 1: 平均产品宽度

```
avgWidth = SUM(规上用户的 width) / COUNT(规上用户)
```
规上用户 = `guishang == '是'` 且 `record_type == 'user'`
取每个用户的 `width` 字段（一个整数，表示该用户覆盖了多少个产品线），求平均。

### KPI 2: 覆盖率

```
coverage = 规上客户数 / 总客户数 × 100
```
规上客户 = `guishang == '是'` 且 `record_type == 'cust'`

### KPI 3: 规上客户数 / 规上用户数

```python
scaleCustomers = COUNT(DISTINCT 规上客户 name)
scaleUsers     = COUNT(DISTINCT 规上用户 name)
totalCustomers = COUNT(DISTINCT 所有客户 name)
```

### KPI 4: 产品覆盖率（每个产品被多少客户覆盖）

```python
# 遍历所有规上客户的 prods_json，统计每个产品被覆盖的次数
for r in 规上客户:
    prods = json.loads(r.prods_json)   # {"IPC": 1, "NVR": 0, ...}
    for p, v in prods.items():
        if v: prods_cover[p] += 1

# 每个产品的覆盖率
rate = prods_cover[p] / scaleCustomers × 100
```

### KPI 5: 宽度分布（6 桶分桶统计）

```python
WIDTH_BUCKETS = {
    '0':     width <= 0,
    '1-3':   1 <= width <= 3,
    '4-6':   4 <= width <= 6,
    '7-10':  7 <= width <= 10,
    '11-15': 11 <= width <= 15,
    '16+':   width >= 16,
}
# 按每个客户的最大 width 分到对应的桶，统计每个桶有多少客户
```

### KPI 6: 各组平均宽度

```python
# 按 group_name 分组，计算每组内客户的平均 width
avg = SUM(组内所有记录的 width) / COUNT(组内客户)
```

### KPI 7: 热力图数据

```python
# 27产品 × 每个产品被多少客户覆盖
total = COUNT(DISTINCT 客户)
for p in WIDTH_PRODUCTS:
    rate = COUNT(覆盖了p的客户) / total × 100
```

### KPI 8: 低宽度分析

```python
# width < 3 的客户视为"低宽度"
lowRate   = COUNT(width < 3 的客户) / total × 100
avgAll    = AVG(所有客户 width)
avgLow    = AVG(低宽度客户 width)
gap       = avgAll - avgLow
# 统计低宽度客户最缺哪些品类
topMissing = 按缺少次数排序的前5个产品
```

## 四、潜力产品分析 — 计算公式

### 数据表: `potential_cust` (客户维度, 21字段)

```
字段: period(月份), dept2/3/4/5(部门层级), sales(销售), product(产品),
      custName(客户名), user_name(用户), amount(销售额万), amount_prev(同期),
      yoy(同比), qty(数量), qty_prev(同期), opps(商机数), opps_prev(同期),
      users(用户数), users_prev(同期)
```

### 数据表: `potential_user` (用户维度, 23字段)

```
字段: 与 cust 类似，但销售额字段叫 out_amt（产品出库额），多了 industry(行业)、custs(客户数)
```

### KPI 1: 总销售额

```python
totalSales = SUM(amount)          # 所有记录的销售额之和
totalPrev  = SUM(amount_prev)     # 同期销售额之和
```

### KPI 2: 同比增长率

```python
yoyGrowth = (totalSales - totalPrev) / totalPrev × 100   # 如果 totalPrev == 0 则返回 0
```

### KPI 3: 产品数量 / 客户数量

```python
productCount  = COUNT(DISTINCT product)     # 有多少个潜力产品有销售
customerCount = COUNT(DISTINCT cust_name)   # 有多少个客户有交易
```

### KPI 4: 客均销售额

```python
avgCustomerAmount = totalSales / customerCount
```

### KPI 5: 涨跌统计

```python
upCount   = COUNT(amount > amount_prev)     # 同比上涨的记录数
downCount = COUNT(amount < amount_prev)     # 同比下降的记录数
newCount  = COUNT(amount_prev == 0 AND amount > 0)  # 新增产品线
```

### KPI 6: 产品排名（按销售额降序）

```python
for each product:
    sales = SUM(amount) GROUP BY product
    prev  = SUM(amount_prev) GROUP BY product
    yoy   = (sales - prev) / prev × 100
    type  = classify(sales, prev)  # "量价齐升" / "量价齐跌" / "新增"
ORDER BY sales DESC
```

### KPI 7: 部门排名（按销售额降序）

```python
for each dept3:
    sales = SUM(amount)
    prev  = SUM(amount_prev)
    yoy   = (sales - prev) / prev × 100
    productCount = COUNT(DISTINCT product)
ORDER BY sales DESC
# 排除: 管理部、深圳业务中心、运营部
```

### KPI 8: 团队 × 产品矩阵

```python
# 按 dept4(小组) × product 交叉聚合销售额
for each (dept4, product):
    sales = SUM(amount)
# 结果: [{ team: "客户销售一组", dept: "客户销售一部", products: { IPC: 380, NVR: 180, ... }}]
```

### KPI 9: 销售额构成（按产品）

```python
for each product:
    total = SUM(amount) GROUP BY product
ORDER BY total DESC
# 用于饼图/柱状图
```

### KPI 10: 四象限分析（量价）

```python
for each product:
    amt_yoy = (SUM(amount) - SUM(amount_prev)) / SUM(amount_prev) × 100   # X轴: 金额同比
    qty_yoy = (SUM(qty) - SUM(qty_prev)) / SUM(qty_prev) × 100            # Y轴: 数量同比
    quadrant = classify(amt_yoy, qty_yoy)  # 象限: 量价齐升/量价齐跌/量增价减/量减价增
```

### KPI 11: 差距看板 (Scorecard)

```python
for each dim (dept/group/person):
    sales = SUM(amount), prev = SUM(amount_prev)
    customers = COUNT(DISTINCT cust_name)
    products  = COUNT(DISTINCT product)
    yoy = (sales - prev) / prev × 100
ORDER BY selected_metric DESC
```

## 六、关键计算模式总结

| 模式 | SQL 操作 | 场景 |
|------|---------|------|
| 简单求和 | `SUM(amount)` | 总销售额 |
| 去重计数 | `COUNT(DISTINCT name)` | 客户数、产品数 |
| 分组聚合 | `GROUP BY product` | 产品排名 |
| 同比计算 | `(SUM(amount) - SUM(amount_prev)) / SUM(amount_prev) × 100` | 所有同比指标 |
| 分桶统计 | Python `if/elif` 判断 + 字典计数 | 宽度分布 |
| 交叉聚合 | `GROUP BY group, product` | 团队×产品矩阵 |
| JSON 遍历 | Python `json.loads(prods_json)` + 字典累加 | 产品覆盖率 |
| 角色过滤 | `filter_by_scope(query, model, user)` | 数据隔离 |
| 部门排除 | `~PotentialCust.dept3.in_(EXCLUDED_DEPTS)` | 排除运营/管理部 |

## 七、筛选维度对照

每个分析页面都有三个筛选维度，它们对应数据表中的字段：

| 筛选 | 产品宽度表字段 | 潜力产品表字段 |
|------|-------------|-------------|
| 部门 | `WidthRecord.dept` | `PotentialCust.dept3` |
| 小组 | `WidthRecord.group_name` | `PotentialCust.dept4` |
| 人员 | `WidthRecord.sales` | `PotentialCust.sales` |

筛选顺序：先数据隔离（角色级强制过滤），再用户选择的级联筛选。
