# 产品分析一体化平台 — 前后端架构设计 V3.0

## 一、系统概述

产品分析一体化平台是基于 B/S 架构的企业级数据分析系统，面向销售管理团队，提供产品宽度分析和潜力产品分析两大核心模块，支持从部门→小组→个人的三级数据下钻。

---

## 二、技术选型

| 层级 | 技术 | 说明 |
|---|---|---|
| 前端框架 | Vue 3.4 + TypeScript 5.x | Composition API + `<script setup>` |
| 状态管理 | Pinia 2.x | 模块化 Store，支持 DevTools |
| UI 组件 | Element Plus 2.x | 企业级组件库 |

| 缓存 | Redis 7.x | 会话 + 热点数据缓存 |

| API 文档 | SpringDoc OpenAPI 3.0 | 自动生成 Swagger UI |
| 安全 | Spring Security + JWT | RBAC 权限模型 |

### 3.4 组件通信规范

```
FilterBar (全局筛选器)
  │ props: filters, options
  │ emit: @change → 更新 useFilterStore
  ▼
useFilterStore (全局状态)
  │ 各 Tab 组件通过 storeToRefs 读取 filters
  ▼
TabComponent (业务组件)
  │ 从 Store 获取 filteredData
  │ 纯展示：不直接调用 API
  ▼
子组件 (KpiCards/Chart/Table)
  │ props 传入数据
  │ emit 传出事件（点击/下钻）
```

### 4.5 数据权限 AOP

```java
@Aspect
@Component
public class DataScopeAspect {
    @Around("@annotation(dataScope)")
    public Object around(ProceedingJoinPoint pjp, DataScope dataScope) {
        // 从 SecurityContext 获取当前用户角色
        // admin/gm/operation → 不过滤
        // director → WHERE dept_id = currentUser.deptId
        // manager → WHERE group_id = currentUser.groupId
        // sales → WHERE owner_id = currentUser.userId
        return pjp.proceed();
    }
}
```
