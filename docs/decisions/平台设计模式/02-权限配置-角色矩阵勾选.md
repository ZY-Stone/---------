# 权限配置 — 角色矩阵勾选保存

> 平台现有设计，从 `index.html` + `app.js` `renderRoles` / `saveRolePerms` 提取。

## 🗣 大白话

一个 7×10 的表格（角色 × 权限模块），每个单元格是一个勾选框。管理员勾选后点「保存」，一次性批量提交到后端。顶部有说明文字和保存按钮。

---

## UI 结构

```html
<!-- 提示 + 保存按钮 -->
<div>
  <div>勾选模块授予权限，修改后点击保存</div>
  <button onclick="App.saveRolePerms()">💾 保存</button>
</div>

<!-- 矩阵表格 -->
<div class="table-wrap">
  <table class="cu-table">
    <thead id="aRolesHead"></thead>   ← 动态生成表头

  </table>
</div>
```

## 渲染逻辑

```javascript
// 表头动态生成
var modKeys = ['overview','width','potential','users_mgmt','roles_mgmt','audit_log','backup','export_data','import_data'];
var modLabels = { overview:'数据总览', width:'产品宽度', potential:'潜力产品', users_mgmt:'用户管理', ... };

thead = '<tr><th>角色</th><th>名称</th>';
modKeys.forEach(function(k) { thead += '<th>' + modLabels[k] + '</th>'; });
thead += '<th>数据范围</th></tr>';

// 每行渲染（从后端拉取的数据或本地 ROLE_PERMISSIONS）
App._roleEditBuffer.map(function(r, ri) {
  var cells = modKeys.map(function(k) {
    var checked = r.modules[k] === 1 ? ' checked' : '';
    return '<td><input type="checkbox" ' + checked +
      ' onchange="App._roleEditBuffer[' + ri + '].modules.' + k + '=this.checked?1:0"></td>';
  }).join('');
  return '<tr><td>' + r.role + '</td><td>' + r.name + '</td>' + cells +
    '<td>' + scopeLabel + '</td></tr>';
});
```

## 保存逻辑

```javascript
// 点击保存 → 转成后端格式 → 一次批量 PUT
rolesPayload = buffer.map(function(r) {
  return {
    role: r.role,
    overview: r.modules.overview === 1,
    width: r.modules.width === 1,
    // ... 10个字段
    data_scope: r.data_scope
  };
});

App.API.updateRolesBatch(rolesPayload)  // PUT /api/permission/roles
  .then → 显示 "✅ 权限已保存"
  .catch → 保存到 localStorage 兜底
```

## 关键设计

- **编辑缓冲区** (`App._roleEditBuffer`) — 勾选后不直接提交，点保存才批量发送
- **后端优先** — 页面打开时从 `GET /api/permission/roles` 拉数据构建表格
- **本地兜底** — 后端不可用时读取 `App.ROLE_PERMISSIONS` + `localStorage`
- **数据范围不可编辑** — 仅展示（角色级别固定，由后端 RolePermission 表决定）
