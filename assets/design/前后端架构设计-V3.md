# 产品分析一体化平台 — 前后端架构设计 V3.0

## 一、系统概述

产品分析一体化平台是基于 B/S 架构的企业级数据分析系统，面向销售管理团队，提供产品宽度分析和潜力产品分析两大核心模块，支持从部门→小组→个人的三级数据下钻。

---

## 二、技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript 5.x | Hooks + 函数组件 |
| 状态管理 | Zustand 5.x | 轻量、TS 原生支持 |
| 样式 | Tailwind CSS 4.x | 原子化 CSS，JIT 编译 |
| 图表 | ECharts 5.5 | Canvas 渲染，一个 option 对象搞定所有图表 |
| 构建 | Vite 6.x | 秒级 HMR |
| 后端框架 | Python FastAPI + Pydantic v2 | 自动 OpenAPI 文档，类型安全 |
| ORM | SQLAlchemy 2.0 (Mapped + mapped_column) | 异步就绪，声明式模型 |
| 迁移 | Alembic | 数据库版本管理，可追溯可回滚 |
| 数据库(开发) | SQLite | 零配置，单文件部署 |
| 数据库(生产) | PostgreSQL（OLTP）+ ClickHouse（OLAP） | PG 管业务，CK 管海量聚合 |
| 分析引擎 | SQL 预聚合 → Pandas 深度计算 | SQL 做 COUNT/DISTINCT/分组，Pandas 做矩阵/趋势 |
| API 文档 | FastAPI 自动生成 Swagger UI | `/docs` 即文档 |
| 安全 | JWT + bcrypt | 基于角色的数据权限隔离 |

### 3.3 Store 设计（数据联动核心）

```typescript
// stores/filterStore.ts — 全局筛选
interface FilterStore {
  dateStart: string; dateEnd: string;
  dept: string; group: string; person: string;
  setDept: (v: string) => void;  // 自动重置 group='all', person='all'
  setGroup: (v: string) => void; // 自动重置 person='all'
  setPerson: (v: string) => void;
}

// stores/widthStore.ts — 产品宽度
interface WidthStore {
  userGS: WidthRecord[]; custGS: WidthRecord[];
  kpi: WidthKpi;                   // 计算 getter
  productCoverage: ProductCoverage[];
  teamWidthRank: TeamRank[];
  importExcel: (file: File) => Promise<{ nu: number; nc: number }>;
}
```

**数据流：**
```
Excel 导入 → widthStore.importExcel(file)
  → userGS / custGS 更新
  → kpi / productCoverage / teamWidthRank 自动重算（Zustand 响应式）
  → 所有组件自动重渲染
  → 无需手动调用刷新函数
```

### 3.4 组件通信规范

```
FilterBar (筛选器)
  │ 调用 filterStore.setDept()
  ▼
filterStore (Zustand)
  │ dept/group/person 级联变化
  ▼
widthStore / potentialStore
  │ getter 自动重算 filteredData → kpi → coverage → rank
  ▼
各页面组件 (Overview / Width / Potential)
  │ 从 Store 读取最新数据，纯展示
  ▼
子组件 (KpiCard / ECharts)
  │ props 传入数据
```

### 4.3 数据权限隔离

```python
# services/data_service.py — 基于角色的数据过滤
def apply_data_scope(query, user):
    if user.role in ('admin', 'gm', 'operation'):
        return query  # 全量数据
    if user.role == 'director':
        return query.filter(Model.dept_id == user.dept_id)
    if user.role == 'manager':
        return query.filter(Model.group_id == user.group_id)
    return query.filter(Model.owner_id == user.id)
```

## 五、数据流设计

```
Excel 上传
  → 前端 xlsx 解析 JSON
  → widthStore.importExcel(file)  // 同时更新内存 + localStorage
  → 可选: POST /api/import/width  // 后端持久化到 SQLite
  → Zustand Store getter 自动重算
  → 所有组件自动响应式重渲染
  → ECharts option 按需更新
```

```
筛选条件变化
  → filterStore.setDept('客户销售一部')
  → group='all', person='all' 自动级联重置
  → widthStore.kpi / potentialStore.overview 重算
  → 所有依赖组件自动重渲染
```
