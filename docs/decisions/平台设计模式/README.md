## 和「沉淀与复用」的区别

| | 沉淀与复用 | 平台设计模式 |
|------|-----------|-------------|
| 内容 | 可复制的代码块 + 适配说明 | 平台现有设计的样子 + 为什么这么设计 |
| 用途 | 复制到新项目直接用 | 参考设计思路，自己实现 |
| 语言 | 技术文档 | 大白话 + 知识点 |
