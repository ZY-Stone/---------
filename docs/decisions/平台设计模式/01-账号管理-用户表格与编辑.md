# 账号管理 — 用户表格与编辑弹窗

> 平台现有设计，从 `index.html` + `app.js` 直接提取。

## 🗣 大白话

一个带搜索筛选的用户管理表格。顶上有搜索框和角色/状态下拉，表格每行显示用户信息，行尾有角色切换下拉 + 编辑按钮 + 删除按钮。右上角「新增用户」按钮打开编辑弹窗。

---

## 表格行渲染逻辑

```javascript
// 每行的数据结构
users.forEach(function(u) {
  // u = { id, username, name, role, dept_name, group_name, data_scope }

  // 角色显示为彩色 chip
  var r = App.USER_ROLES[u.role];  // { badge: '总监', color: '#0891b2' }
  var roleTag = '<span style="background:' + r.color + '18;color:' + r.color;
  roleTag += ';padding:1px 8px;border-radius:10px;font-size:11px">' + r.badge + '</span>';

  // 数据范围用颜色区分
  var scopeColor = { all: '#059669', dept: '#2563eb', group: '#ea580c', self: '#64748b' }[u.data_scope];
  var scopeLabel = { all: '全部', dept: '本部门', group: '本小组', self: '本人' }[u.data_scope];

  // 表格行
  h += '<tr>';
  h += '<td><strong>' + u.username + '</strong></td>';
  h += '<td>' + u.name + '</td>';
  h += '<td>' + roleTag + '</td>';
  h += '<td style="color:#94a3b8">' + u.role + '</td>';
  h += '<td>' + u.dept_name + '</td>';
  h += '<td>' + u.group_name + '</td>';
  h += '<td style="color:' + scopeColor + '">' + scopeLabel + '</td>';
  h += '<td>';
  h += '<select onchange="App.changeUserRole(' + u.id + ',this.value)">';  // 角色切换
  h += '<button onclick="App.showUserForm(' + u.id + ')">✎</button>';      // 编辑
  h += '<button onclick="App.deleteUser(' + u.id + ')">✕</button>';        // 删除
  h += '</td></tr>';
});
```

## 编辑弹窗结构

```html
<h3>＋ 新增用户 / ✎ 编辑用户</h3>
```

## 排序规则

用户列表先按部门顺序排，再按角色权重排（admin→gm→operation→director→manager→interface→sales），最后按用户名排序。admin 用户不可删除。
