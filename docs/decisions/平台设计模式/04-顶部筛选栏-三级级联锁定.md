# 顶部筛选栏 — 三级级联 + 角色自动锁定

> 平台现有设计，从 `index.html` + `app.js` 筛选相关函数提取。

## 🗣 大白话

每个数据页面（总览/宽度/潜力）顶上都有一个筛选栏。三个下拉框：部门、小组、人员。它们会联动：选部门后小组只显示该部门下的，选小组后人员只显示该组内的。更重要的是，登录后根据角色自动锁定：总监的部门下拉锁死在自己部门、销售的三个下拉全锁。

---

## HTML 模板（每个页面复用同一套）

```html
<div class="filter-bar">
  <!-- 日期 -->
  <div class="filter-group">
    <label>日期</label>
    <span id="ov-date-range" onclick="App.toggleDatePicker('ov')">
      <span id="ov-date-text">2026-07-01 ~ 2026-07-16</span> 📅
    </span>
  </div>

  <!-- 三级级联 -->
  <div class="filter-group">
    <label>👥 部门</label>
    <select class="filter-dept" onchange="App.onDeptChange('page-overview')"></select>
  </div>
  <div class="filter-group">
    <label>小组</label>
    <select class="filter-group-sel" onchange="App.onGrpChange('page-overview')"></select>
  </div>
  <div class="filter-group">
    <label>个人</label>
    <select class="filter-person" onchange="App.onPersonChange('page-overview')"></select>
  </div>

  <button class="btn-ghost" onclick="App.resetFilters('page-overview')">🔄 重置</button>
</div>
```

## 三个下拉的 CSS class 约定

| 下拉 | CSS class | 作用 |
|------|-----------|------|
| 部门 | `.filter-dept` | 一级 |
| 小组 | `.filter-group-sel` | 二级，依赖部门 |
| 人员 | `.filter-person` | 三级，依赖小组 |

所有数据页面共用这组 class，通过 `pageId` 参数区分。

## 级联回调链

```
换部门 → onDeptChange(pageId)
  ├─ 重置小组 = 'all'
  ├─ 重置人员 = 'all'
  ├─ populateGrpDropdown(pageId)    ← 只显示新部门下的小组
  ├─ populatePersonDropdown(pageId)  ← 重置为空
  └─ refreshPageData(pageId)         ← 重新拉数据

换小组 → onGrpChange(pageId)
  ├─ 反向回填部门（根据小组查所属部门）
  ├─ 重置人员 = 'all'
  ├─ populatePersonDropdown(pageId)  ← 只显示新小组下的人员
  └─ refreshPageData(pageId)

换人员 → onPersonChange(pageId)
  ├─ 反向回填小组和部门
  └─ refreshPageData(pageId)
```

## 角色锁定规则

| 角色 | 部门 | 小组 | 人员 |
|------|------|------|------|
| admin / gm / operation | 全部可选 | 全部可选 | 全部可选 |
| director / interface | 🔒 锁死自己部门 | 可选 | 可选 |
| manager | 🔒 锁死自己部门 | 🔒 锁死自己组 | 组内可选 |
| sales | 🔒 锁死 | 🔒 锁死 | 🔒 锁死自己 |

## 锁定实现

锁定逻辑内置在 `populateDeptDropdown` / `populateGrpDropdown` / `populatePersonDropdown` 三个函数里：

```javascript
// 部门：受限角色不显示"全部"选项
if (role !== 'admin' && role !== 'gm' && role !== 'operation') {
  sel.innerHTML = depts.map(...).join('');  // 不包含 <option value="all">
  sel.disabled = true;  // 只有一个选项时直接禁用
}

// 小组：manager 和 sales 锁定
if (role === 'manager') { sel.disabled = true; }
if (role === 'sales')   { sel.disabled = true; }

// 人员：sales 锁定
if (role === 'sales')   { sel.value = user.username; sel.disabled = true; }
```
