📊 综合分计算逻辑

综合分满分 100 分，由四个维度按权重加权得出：

个人综合分 = 产品宽度得分 + 场景数字化得分 + 潜力产品得分 + 新品得分
计分规则（分段线性映射）：设 r ＝ 个人值 ÷ 全员平均值
① 产品宽度：r=1.0 → 80%权重，r=1.5 → 封顶100%，保底20% → ×35%
② 场景数字化：r=1.0 → 80%权重，r=2.0 → 封顶100%，保底10% → ×10%
③ 潜力产品：r=1.0 → 80%权重，r=2.0 → 封顶100%，保底10% → ×45%
④ 新品：r=1.0 → 80%权重，r=2.0 → 封顶100%，保底10% → ×10%
团队人均综合分 = 团队内所有人员个人综合分的平均值
※ 产品宽度封顶1.5倍平均（超平均50%即拿满分权重），其余维度封顶2.0倍平均（超100%即满分）。
※ 若某维度全员数据均为 0，则该维度得分自动为 0，不影响其他维度。
※ 各维度设有保底下限（产品宽度20%，其余维度10%），避免极端低分。
※ 团队排名按人均综合分排序，避免人多占便宜。

❓ 常见问题

综合维度数据不一致？

v3.0 已修复：综合维度下的产品宽度统计口径已与产品宽度维度完全一致（总品种数 ÷ 规上记录数）。

切换团队数据不刷新？

v3.0 已修复：切换团队（人员为"全部人员"时）可正常刷新数据和排名表。如仍有问题，可点击 🔄 刷新 按钮手动触发。

综合分是如何计算的？

综合分采用分段线性映射：以全员平均为基准（r=个人值÷平均值）。达到平均→80分基准；产品宽度超平均50%(r=1.5)封顶，其余维度超平均100%(r=2.0)封顶；均保底10%~20%避免分数过低。总分最高100分。默认权重：35%/10%/45%/10%，可通过"⚙ 配置权重"自定义。

潜力产品同比调整：在基础得分上按同比增长率 ± 分调整，每 ±10% → ±1分；同期无数据（potLast=0）时不调整；加分后不超过权重总分，减分后不低于权重×10%。

点击导出后没有反应？

请先确保已上传数据并选择维度查看统计结果，导出按钮才会正常工作。

AI 分析报错怎么办？

检查 API Key 是否正确，模型名称是否匹配。自定义 Endpoint 需符合 OpenAI 兼容格式。

产品悬浮气泡在哪些地方生效？

所有含"产品列表"的表格单元格 + 场景数字化/潜力产品/新品的产品排名表产品名列，均支持鼠标悬浮查看贡献明细。

增量对比功能如何使用？

分别上传「基线数据」和「当前数据」两个文件后，视图切换器会自动激活。点击"当前数据" → 勾选"显示增量（与基线对比）"即可在所有五个维度查看排名变化和指标增量。AI分析也会自动包含增量解读。

为什么个人维度下团队排名不是全第1名？

v2.0 已修复：个人视图下的团队排名基于全量数据计算，当前人员所属团队蓝色高亮并显示 ⭐ 标记，体现真实排名。
