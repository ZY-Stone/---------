# 组织目录 — 部门 / 小组 / 人员 三级层级

> 平台现有设计 + 实际运行中的数据。以后同类功能可直接参考这个组织架构和权限设置。

---

## 🗣 大白话

整个平台的数据都围绕"组织"来划分：部门 → 小组 → 人员。每个用户属于一个部门和一个组（也可无组），每条销售数据也标记了部门、组、销售姓名。权限隔离也按这个层级来。


## 过滤函数层级逻辑

```
getFilteredDepts()          → 只看自己的部门（受限角色）
getFilteredGroups(dept)     → 按部门筛选 + 角色限制
getFilteredPersons(dept, grp) → 按部门+小组筛选 + 角色限制
```

三个过滤函数共用同一个模式：先按角色限制（只看自己的），再按参数限制（级联）。
