## 2. 数据存储层（两个模块完全隔离）

### 产品宽度数据
```js
App.ImportData = {
  UserGS: [],   // 规上用户宽度明细
  CustGS: [],   // 规上客户宽度明细
  currentView: 'user'
}
```

### 潜力产品数据
```js
App.ImportPotential = {
  CustRAW: [],  // 潜力产品-客户原始数据
  UserRAW: [],  // 潜力产品-用户原始数据
  currentDS: 'cust'
}
```

## 3. 数据持久化（刷新不丢失）

```js
// 导入时保存
localStorage.setItem('pa_import_cust', JSON.stringify(App.ImportPotential.CustRAW));
localStorage.setItem('pa_import_user', JSON.stringify(App.ImportPotential.UserRAW));
localStorage.setItem('pa_width_cust', JSON.stringify(App.ImportData.CustGS));
localStorage.setItem('pa_width_user', JSON.stringify(App.ImportData.UserGS));

// 初始化时恢复
App.ImportPotential.init = function() {
  var saved = localStorage.getItem('pa_import_cust');
  if (saved) App.ImportPotential.CustRAW = JSON.parse(saved);
  // ... same for UserRAW
};
```

## 4. 渲染管道

```
Excel导入 → handleUpload → 写入 DataStore + localStorage
  → updatePotential() / updateWidth()
  → 所有Tab渲染函数读取 DataStore
  → 基于筛选state过滤 → 计算指标 → 渲染DOM
```

关键约束：
- **禁止硬编码数据**：所有Tab从 DataStore 读取，无数据时显示空状态
- **同一模块Tab共享状态**：updatePotential() 刷新该模块所有Tab
- **顶部筛选全局同步**：切换筛选 → refreshPageData → 重新渲染

## 5. 筛选状态传递

```js
// 每个渲染函数接收筛选state
function renderXxx(state) {
  var team = state.team, group = state.group, person = state.person;
  var data = DataStore.slice(); // 从总表拷贝
  
  // 按筛选过滤
  if (team !== 'all') data = data.filter(r => r.dept === team);
  if (group !== 'all') data = data.filter(r => r.group === group);
  if (person !== 'all') data = data.filter(r => r.person === person);
  
  // 基于过滤子集计算指标
  var metrics = computeFrom(data);
  renderToDOM(metrics);
}
```
