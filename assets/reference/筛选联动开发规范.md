# 产品分析一体化平台 — 筛选联动开发规范

## 1. 筛选层级与优先级

```
个人 > 小组 > 部门 > 全部部门
```

顶部筛选器三个下拉：部门 → 小组 → 个人，上级切换时下级自动重置为 `all`。

## 2. 获取当前筛选状态

```js
var state = App.getFilterState('page-potential');
// state = { team: '行业二部', group: '政府行业组', person: 'all' }
// 'all' 表示未选中该层级
```

## 3. 关键辅助函数

### 3.1 产品级缩放系数（体现部门产品侧重差异）

```js
var ps = App._getProductScale('NVR', state);
// 全部部门 → 1.0
// 行业二部（NVR占35%）→ 0.28 × (35/16.7) ≈ 0.59
// 大客户部（NVR占6%）→ 0.28 × (6/16.7) ≈ 0.10
```

### 3.2 筛选范围内总数（客户/用户）

```js
var scopeTotal = App._getScopeTotal(state, 'cust'); // 客户数
var scopeUserTotal = App._getScopeTotal(state, 'user'); // 用户数
```

### 3.3 基础统一缩放（仅用于非产品维度的总量缩放）

```js
var sf = 1;
if (state.person !== 'all') sf = 0.03;
else if (state.group !== 'all') sf = 0.10;
else if (state.team !== 'all') sf = 0.28;
```

## 4. 渲染函数模式

```js
App.renderXxxCard = function(state) {
  // ── 1. 获取筛选状态 ──
  state = state || App.getFilterState('page-potential');
  var team = state.team, group = state.group, person = state.person;

  // ── 2. 筛选数据源 ──
  var items = 原始数据.filter(function(r) {
    if (team !== 'all' && r.dept !== team) return false;
    if (group !== 'all' && r.group !== group) return false;
    if (person !== 'all' && r.sales !== person) return false;
    return true;
  });

  // ── 3. 计算指标（基于筛选子集） ──
  items.forEach(function(r) {
    var ps = App._getProductScale(r.product, state);  // 产品×部门级缩放
    var scopeTotal = App._getScopeTotal(state, 'cust'); // 范围总数
    // ... 业务计算
  });

  // ── 4. 渲染到 DOM ──
  var tbody = document.getElementById('xxx-body');
  if (tbody) { tbody.innerHTML = ...; }

  // ── 5. 更新范围标签 ──
  var scopeLabel = person !== 'all' ? person : group !== 'all' ? group : team !== 'all' ? team : '全公司';
};
```

## 5. 接入刷新管道

### 方式一：挂到 `updatePotential`（推荐 — 自动跟随筛选刷新）

```js
// 在 App.updatePotential 中添加：
try { App.renderXxxCard(state); } catch(e) { console.warn('renderXxxCard 失败:', e); }
```

### 方式二：挂到 Tab 渲染函数（仅在该 Tab 可见时刷新）

```js
// 在 App.renderPotentialTeamTab 中添加：
try { App.renderXxxCard(state); } catch(e) { ... }
```

## 6. 数据约束 Checklist

| 约束项 | 检查 |
|---|---|
| 所有指标**不超出选中维度范围** | 禁止直接从全局大盘拷贝数据，必须基于 `state` 过滤 |
| 覆盖率 = 已覆盖 / **范围总数**（非全局总数） | 使用 `App._getScopeTotal(state, type)` |
| 销量/金额使用**产品级缩放**而非统一 sf | 使用 `App._getProductScale(product, state)` |
| 范围标签实时更新 | `scopeLabel` 变量 |
| 切换任一筛选 → 全页面统一刷新 | 挂到 `updatePotential` |
| 名称列表、分类清单基于**筛选子集**生成 | 不要让 NVR 的组合固定写死在每个卡里，应从数据源筛选 |

## 7. 常用数据源

| 数据 | 路径 |
|---|---|
| 部门列表 | `App.DEPTS` — `{ n, cw, cov, yoy, ld }` |
| 小组列表 | `App.GROUPS` — `{ n, dept, cw, cov, yoy, ld }` |
| 人员列表 | `App.PERSONS` — `{ n, dept, grp, cw, cov }` |
| 12个潜力产品 | `App.ALL_POT_PRODUCTS` |
| 部门×产品份额 | `App.DEPT_PRODUCT_SHARE['行业二部']['NVR']` → `35` |
| 客户原始数据 | `App.ImportPotential.CustRAW` |
| 用户原始数据 | `App.ImportPotential.UserRAW` |
